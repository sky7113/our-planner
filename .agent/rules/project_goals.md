# Project: The Butterfly Mansion (Chou Yashiki)

User: Raksha Tiwari (AIML Student, MITS Gwalior).

Theme: 'Shinobu Kocho' aesthetic. Purple/Teal gradients, glassmorphism, butterfly motifs.

Core Philosophy: 'Gentle Tech'. The app adapts to her nervous system.

# Key Features (The Living Sanctuary):

Cycle-Syncing Interface: The dashboard UI must change based on her energy levels (Follicular = Ambitious/Career Mode; Luteal = Comfort/Sanctuary Mode).

The Sanctuary Button: A prominent panic button that triggers calming breathing animations and reassuring text from Amber.

Career Accelerator: A Kanban board for Internship tracking and a 'Code Inspector' toggle to teach her Next.js structure.

Smart Budget: A spending tracker that suggests 'Comfort Food' (Zomato/Swiggy) when she is down.

Memory Gallery: An audio-visual gallery of shared memories (Garba, Guitar, Gwalior).

# Coding Standards:

Use Shadcn UI principles for clean, accessible design.

Write clear, educational comments in the Python backend so Raksha can learn from the code.

Prioritize 'Soft' animations (slow fades, spring physics) over sharp movements.
